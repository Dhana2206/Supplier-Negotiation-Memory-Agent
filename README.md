# Supplier Negotiation Memory Agent

AI-powered B2B supplier negotiation assistant with persistent Hindsight memory.

## 🚀 Overview

Supplier Negotiation Memory Agent helps procurement teams make better negotiation decisions by remembering previous supplier negotiations and using relevant historical context during future negotiations.

The system combines:

- Current supplier quote
- Supplier-specific negotiation history
- Product-specific negotiation history
- Previous successful concessions
- AI-generated negotiation strategy
- Counter-offer recommendations
- Negotiation outcomes

## 🧠 How It Works

```text
Current Quote
      ↓
Supplier + Product Memory
      ↓
Hindsight Recall
      ↓
AI Reflection
      ↓
Negotiation Strategy
      ↓
Counter Offer
      ↓
Negotiation Outcome
      ↓
Hindsight Memory
      ↓
Future Negotiations
